## 2024-05-07 - Screen Reader & Keyboard Navigation Improvements
**Learning:** Real-time UI components with low-frequency updates (like the alert log and risk badge) need `aria-live="polite"` to ensure they are announced by screen readers without being overwhelming. High-frequency updates (like 10Hz telemetry charts) should NOT have this to prevent overwhelming the user. Also, custom interactive UI controls in the Aegis Vision design system (like `.btn` and `.slider`) lack native focus styles and require explicit `:focus-visible` outlines for keyboard accessibility.
**Action:** When adding new interactive controls or real-time low-frequency status elements to the dashboard, ensure `:focus-visible` states are implemented using the existing `--primary` CSS variable, and apply `aria-live="polite"` specifically to low-frequency alert containers.
